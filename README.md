# Crônicas da Ressonância — Ficha Digital Alpha

Aplicação local em HTML, CSS e JavaScript para gerenciamento de personagens e Crônicas.

## Recursos atuais

- criação, importação, exportação, duplicação e exclusão de personagens;
- ficha de personagem e Rolador Rápido com histórico;
- Crônicas com Visão Geral, Elenco, Participantes e Confrontos;
- Escudo do Mestre protegido localmente, com Caçadores e Combates;
- preparação, início, execução e encerramento de Confrontos;
- persistência local de personagens e IndexedDB v6 para Crônicas.

## Execução

Abra `index.html` por um servidor HTTP local. Não é necessário instalar dependências nem executar uma etapa de build.

Para publicar no GitHub Pages, mantenha `index.html`, `script.js` e `style.css` na raiz e preserve as pastas `assets`, `css` e `js`.

## Dados locais

Personagens, Crônicas e demais registros permanecem no armazenamento do navegador. Esses dados não fazem parte dos arquivos publicados e podem variar conforme endereço, porta e navegador utilizados.

## Aviso

Esta é uma versão **Alpha**. Recursos, regras, textos e aparência ainda podem mudar após os testes com jogadores.
