# Crônicas da Ressonância — Ficha Digital v0.3-dev

Versão de desenvolvimento baseada na v0.2.1 estável.

## Novidades

- Distribuição inicial de atributos: todos começam em 1 e possuem 1 ponto adicional no nível 1.
- Botões de + e − nos cinco atributos.
- Cálculo automático de PV, PN e PS máximos para Vanguarda, Atirador, Arcano e Guardião.
- Subir de nível altera somente os valores máximos; os valores atuais são preservados.
- Habilidade inicial automática ao escolher a classe:
  - Vanguarda: Postura de Combate
  - Atirador: Mira Precisa
  - Arcano: Canalização Arcana
  - Guardião: Pulso Restaurador
- Trocar de classe substitui somente a habilidade automática e preserva habilidades manuais.
- Armazenamento separado da v0.2.1 para proteger o backup estável no mesmo navegador.

## Arquivos

- `index.html`
- `style.css`
- `script.js`

Abra `index.html` no computador. Para celular, use a versão portátil em arquivo único incluída no pacote de distribuição.
